# 模块内容 JSON 规范（S8 内容填充用）

每个技能模块一个 JSON 文件：`backend/content/module_<code>.json`

## 顶层结构

```json
{
  "code": "labor-law",          // 模块编码（与现有 skill_modules.code 一致）
  "name": "劳动法与合规",
  "icon": "⚖️",
  "description": "一句话模块简介",
  "chapters": [ {章节对象}, ... ],   // 3 个章节
  "exam": { 考核卷对象 }
}
```

## 章节对象

```json
{
  "title": "第一章 劳动合同的订立与试用期",
  "summary": "一句话概要",
  "content": "# 标题\n\n## 案例引入：xxx（先思考，再看下文）\n\n{莱茵科技剧情，只描述问题，不剧透解法，结尾引导思考}\n\n## 带着问题学\n\n> 本章知识点将帮你解决…（2~3 个问题）\n\n---\n\n## 一、概念…\n\n{Markdown 讲解，含表格/要点}\n\n## 进阶视角：…\n\n{书单五层补充}\n\n## 案例复盘：xxx\n\n{林晓的实际做法与结果 + 对照思考}\n\n## 费曼自检\n\n{用自己的话复述验证}",
  "questions": [ 题目对象 × 5 ],      // 知识题
  "case_questions": [ 题目对象 × 2 ]  // 案例题（题干以【案例】开头）
}
```

## 题目对象

```json
{
  "qtype": "single",              // single / multiple / judge
  "stem": "题干",
  "options": [ {"key": "A", "text": "选项"} ],
  "answer": ["A"],                 // 正确答案 key 列表（多选多个）
  "explanation": "答案解析"
}
```
判断题为两个选项 A=正确 / B=错误。知识题 5 道、案例题 2 道（题干以【案例】开头，基于莱茵科技剧情）。

## 考核卷对象

```json
{
  "title": "劳动法与合规 · 模块考核",
  "description": "覆盖全部章节，满分 100 分，100 分通过（随机抽题组卷）",
  "pass_score": 100,
  "duration_minutes": 15,
  "questions": [ 题目对象 × ≥7 ],   // 考核知识题（需 ≥7 道供随机抽题）
  "case_questions": [ 题目对象 × 3 ] // 考核案例题（3 道）
}
```

## 硬性要求

1. **内容准确**：概念以德斯勒《人力资源管理》/诺伊《人力资源管理》等教材级定义为准
2. **案例统一**：必须使用「莱茵科技」×「林晓」贯穿案例（CEO 王总、产品总监陈工、销售总监刘姐、导师赵姐），禁止自创其他公司/人物；各模块时间线：绩效=T1、薪酬=T2、培训=T3、员工关系=T4、合规=T5
3. **案例驱动**：章节开头"案例引入"只给问题不剧透；结尾"案例复盘"揭示做法；"费曼自检"结尾
4. **题目严谨**：答案正确、选项合理、解析解释到位
5. **JSON 合法**：严格 JSON 格式（无注释、无尾逗号、字符串正确转义），UTF-8 中文
